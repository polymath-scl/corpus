# The bottom of the scl spectrum in F_2: computed data

Provenance: computed in an AI agent session (Cowork, August 2026) using `scallop`
(Calegari-Walker), built from source. All values were computed in the rigorous
`-cyclic` mode; a sample was re-checked with `-mEXLP` (exact rational arithmetic)
and against the independent `-local` algorithm, and they agree. Every example in
scallop's README reproduced exactly.

The search was exhaustive over all cyclically reduced homologically trivial words
of length <= 20 in F_2, up to the symmetry group generated by cyclic rotation,
inversion and the eight signed permutations of {a,b} -- 185,502 symmetry classes.
Structured families were then scanned out to length 42.

NOT independently verified by a person. Treat as computational evidence.

Throughout, x = a and y = b a b^{-1}. These are conjugate in F_2, which is why the
words below are homologically trivial even though the exponent sums in x and y
separately are not zero.

## Family A  (the extremal one)

    w_n  =  x^n y x^{1-n} y^{-2}
         =  a^n (b a b^{-1}) a^{-(n-1)} (b a^{-2} b^{-1})
         =  a...a b a B A...A b A A B          (|w_n| = 2n + 6)

Equivalently `w_n = a^n u a^{-n} v` with `u = bab^{-1}`, `v = a b a^{-2} b^{-1}`:
a single "twist parameter" n.

More generally, over the whole 4-syllable family `x^p y^q x^{-r} y^{-s}`
with p+q=r+s and 1 <= p,q,r,s <= 8 (266 words computed), the only values
below 3/4 that occur are
1/2, 7/12, 5/8, 13/20, 2/3, 19/28, 11/16, 17/24, 11/15 -- all of the form
3/4 - 1/m, and with `q = 1` the value depends only on p:
`scl(x^p y x^{-r} y^{-s}) = 3/4 - 1/(2p)` whenever p+1 = r+s, r,s >= 1.
