# Licensing

Two regimes, deliberately different.

**Lean source and other code: Apache License 2.0**, with the person who contributed
it named as the author in the file header. This matches Mathlib exactly, so results
proved here can be contributed upstream into Mathlib rather than stranded by an
incompatible licence.

Put this at the top of each Lean file:

```
/-
Copyright (c) 2026 Your Name. All rights reserved.
Released under Apache 2.0 license as described in the file LICENSE.
Authors: Your Name
-/
```

**Records, exposition, figures: CC0 1.0.** CC0 carries a fallback permission for
the several European jurisdictions in which simply declaring something public
domain has no legal effect, which a bare "public domain" statement does not.

**Every contribution carries a sign-off.** Commit with `git commit -s`, which adds
a `Signed-off-by:` line. That is the standard lightweight statement that you have
the right to contribute the material and agree to these terms.

**Two tensions, flagged rather than papered over.** Apache 2.0 requires attribution,
which coexists with but is not identical to the project's "collectively credited"
principle. And material marked as written by an AI assistant is also subject to
that provider's terms of service, which this project cannot override on its own.

Full licence texts belong in this folder as `Apache-2.0.txt` and `CC0-1.0.txt`.
